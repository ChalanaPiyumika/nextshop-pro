# Antoinette Shopify Liquid theme

## Goal
Create a Shopify-uploadable Liquid theme that closely matches the Antoinette storefront currently shown in Lovable, using the supplied Figma home page as the visual reference.

## What will be included
- Matching home page: overlay header, full-image intro, three collection tiles, new arrivals, dark collection feature, editorial statement, studio story, and footer/newsletter.
- Native Shopify product listing, product page, cart drawer/page, search, menus, and checkout links.
- Shopify Theme Editor controls for photos, copy, buttons, colors, spacing, section order, collections, products, menus, and footer content.
- Responsive desktop and mobile layouts using the same typography, palette, image ratios, and restrained gallery styling as the current storefront.
- A validated ZIP package ready for **Online Store → Themes → Add theme → Upload zip file**.

## Technical details
- Shopify Online Store 2.0 structure with Liquid layouts, JSON templates, reusable snippets, section schemas, theme settings, assets, and locale strings.
- No dependency on the Lovable/React storefront after upload.
- Theme defaults will mirror the current Antoinette page; Shopify content can replace every placeholder through Customize.

## Verification
- Validate required Shopify theme structure and Liquid/schema syntax.
- Inspect the ZIP contents and exclude temporary/generated files.
